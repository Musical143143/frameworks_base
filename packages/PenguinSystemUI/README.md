# PenguinSystemUI (ported for Lunaris)

Source ported from Project-PenguinOS/penguin_packages_apps_PenguinSystemUI, branch `celerity`.

This module builds as an overlay on SystemUI-core and SystemUI-application (see Android.bp).
It has not been built or tested against the Lunaris SystemUI tree. Lunaris's SystemUI has changed
internal APIs, so expect build errors until the overlay is reconciled with Lunaris.
